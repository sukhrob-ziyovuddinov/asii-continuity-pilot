# ASII Tajikistan — Institutional Evaluation Pack

## Purpose

This directory contains the controlled institutional-entry material for the ASII Tajikistan evaluation track through 20 September 2026.

The pack is designed to support a transition from **institutional access** to a **credible demonstration** and then to a documented **technical evaluation / controlled PoC / pilot consideration**. It is not evidence that any institution has adopted ASII, approved a pilot, approved a production deployment, or endorsed ASII from a regulatory perspective.

## Positioning

**ASII — Continuity-Native Financial Crime Intelligence Infrastructure for regulated institutions.**

ASII is designed to preserve investigative context, evidence lineage, accountable human review, and regulator-ready reporting preparation across fragmented financial-crime workflows.

The core platform remains jurisdiction-neutral. Tajikistan is the current institutional-evaluation track and is treated as an additive regulatory, language, and operating layer rather than a separate product fork.

## Evaluation corridor

`ACCESS → CREDIBLE DEMO → INSTITUTIONAL EVALUATION`

Success is not a meeting by itself. The intended stage-transition evidence is an identified institutional owner/team plus an official follow-up requesting or agreeing to a next technical, security, evaluation, controlled-PoC, or pilot-consideration step.

## Non-negotiable evaluation controls

- Synthetic data by default.
- No production credentials or production write path.
- No live KYC/KYB, payment, sanctions, or investigation evidence in the initial demonstration.
- No autonomous customer-impacting or regulated decision.
- Human review and disposition remain explicit and accountable.
- Evidence provenance and timeline changes remain reconstructable.
- Generated analytical material is not treated as source evidence.
- Evaluation, controlled PoC, pilot, procurement, and production remain separate gates.

## Public-claim boundary

Do not state or imply any of the following without authoritative evidence:

- bank customer or institutional adoption;
- regulator approval or endorsement;
- accepted PoC or pilot;
- certification;
- production readiness;
- production deployment;
- live institutional data use;
- guaranteed compliance outcome.

## Working language model

- **EN** — canonical technical and architecture layer.
- **RU** — primary Tajikistan institutional operating interface for the current entry cycle.
- **TJ** — minimal official/localized layer where required.

Full Tajik localization is intentionally deferred until an institution or official submission requires it.
