# ASII Тоҷикистон — қабати кӯтоҳи расмӣ

## Мақсад

Ин матн қабати кӯтоҳи забони давлатии лоиҳаи ASII барои марҳилаи шиносоӣ ва арзёбии институтсионалӣ мебошад. Ин **локализатсияи пурраи маҳсулот нест**.

## Дар бораи ASII

**ASII — инфрасохтори иттилоотӣ барои нигоҳ доштани пайдарпайии таҳқиқоти ҷиноятҳои молиявӣ дар ташкилотҳои танзимшаванда.**

Ҳадафи ASII нигоҳ доштани чунин унсурҳо мебошад:

- контексти таҳқиқот;
- манбаъ ва пайдарпайии далелҳо;
- хронологияи амалҳо ва тағйирот;
- саволҳои ҳалнашуда;
- баррасӣ ва тасдиқи инсон;
- асоснокии қарор;
- омода намудани маводи сохторбандӣ барои ҳисоботдиҳӣ ва санҷиш.

ASII барои иваз намудани қарорҳои мутахассиси ваколатдор пешбинӣ нашудааст. Қарорҳои муҳими марбут ба AML/CFT, таҳримҳо, муносибат бо муштарӣ ё ҳисоботдиҳии танзимкунанда бояд аз ҷониби шахси ваколатдори ташкилот баррасӣ ва тасдиқ карда шаванд.

## Марҳилаи аввалини арзёбӣ

Барои арзёбии аввал истифодаи маълумоти **синтетикӣ** пешниҳод мешавад.

Дар ин марҳила талаб карда намешавад:

- дастрасӣ ба маълумоти воқеии муштариён;
- маълумоти воқеии KYC/KYB;
- маълумоти воқеии пардохт ё ҳисобҳо;
- парол, токен ё дигар маълумоти махфии истеҳсолӣ;
- пайвастшавии ҳатмӣ ба системаҳои истеҳсолии бонк;
- қабули қарори танзимшаванда аз ҷониби система бе баррасии инсон.

## Ҷараёни намоишӣ

`Сигнал → Таҳқиқот → Далелҳо → Баррасии инсон → Контексти қарор → Маводи омода барои ҳисобот`

Мақсади намоиш нишон додани он аст, ки баъд аз гузаштани вақт шахси ваколатдор метавонад фаҳмад:

- дар лаҳзаи муайян чӣ маълум буд;
- кадом далелҳо истифода шуданд;
- маълумоти нав кай пайдо шуд;
- кӣ таҳлил ва баррасӣ гузаронд;
- кадом қарор қабул шуд;
- чаро чунин қарор қабул шуд.

## Ҳолати ҳуқуқӣ ва институтсионалӣ

Ин ҳуҷҷат тасдиқ намекунад, ки ASII аз ҷониби Бонки миллии Тоҷикистон, IT Park, ягон бонк ё дигар ташкилоти молиявӣ тасдиқ ё қабул шудааст.

Арзёбӣ, Controlled PoC, pilot, шартнома ва истифодаи истеҳсолӣ марҳилаҳои алоҳида мебошанд ва ҳар кадом метавонад баррасии техникӣ, амниятӣ, ҳуқуқӣ, танзимкунанда ва харидро талаб намояд.

## Қабати Тоҷикистон

Ядрои технологии ASII ягона мемонад. Қабати Тоҷикистон метавонад танҳо талаботи зарурии маҳаллӣ — забон, истилоҳот, манбаъҳои расмии меъёрӣ ва назорати институтсионалӣ — ро илова намояд.

Локализатсияи пурра танҳо дар ҳолате анҷом дода мешавад, ки талаботи воқеии ташкилот ё раванди расмӣ онро зарур гардонад.
