# ASII Tajikistan — Controlled Target Account Map

## Статус и назначение

Рабочая карта маршрутов для достижения институционального доступа до 20 сентября 2026 года. Она фиксирует только проверяемые публичные маршруты и желаемые функциональные роли. Наличие организации в карте **не означает** интерес, договорённость, знакомство, партнёрство или поддержку ASII.

Любое внешнее обращение требует решения Boss и должно фиксироваться в GitHub issue `asii-backend#19`.

## Success evidence

ACCESS считается достигнутым только когда получен официальный ответ, который:

- определяет ответственное лицо/команду; либо
- направляет ASII в Compliance/AML/Financial Monitoring и Technology/Security; либо
- запрашивает briefing, demo, technical/security material или evaluation proposal.

Отправленное сообщение без ответа не является ACCESS. Встреча без документированного следующего шага не является institutional evaluation.

## Follow-up protocol

- Day 0: send approved institutional message through the verified official route.
- Day 2: one concise follow-up if no acknowledgment.
- Day 4–5: use one verified alternative institutional/association route.
- Stop after two unanswered attempts per route unless new evidence justifies continuation.
- Record every reply and stage transition in issue #19; do not place sensitive information in Slack.

## Human gate

Boss approval is required before:

- email, form, call, direct message or event registration;
- naming a specific institution in public material;
- sending an evaluation proposal;
- agreeing scope, timelines, data use, hosting, security obligations or pilot terms.
